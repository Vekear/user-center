# 设计说明（Design Brief）

> 界面方向由 `frontend-design` + `ui-ux-pro-max` 技能驱动，目标很明确：**不做模板脸**。
> 所有变量集中在 [`frontend/src/styles/tokens.css`](../frontend/src/styles/tokens.css)，
> 组件只引用 `var(--*)`，不写死颜色。

## 1. 主张：把"用户中心"做成一册个人档案

大多数用户中心长成同一个样子：居中的登录卡片、圆角阴影统计卡、彩色胶囊状态标签。
这套方案换一个隐喻——**档案册**：纸面、细线、印章、卷号、底册式记录行。

选择这个隐喻的理由来自业务本身：用户中心里的东西（ID、注册时间、最近登录、角色、登录设备）
本质上是**档案条目**，不是仪表盘指标。把它们排成一张可核对的底册，比塞进 4 张彩色卡片更贴近
用户真实要做的事——核对与修改自己的信息。

## 2. 设计变量

### 颜色：暖白纸面 + 深墨 + 靛青 + 琥珀

| 角色 | 变量 | 值 | 用法 |
|---|---|---|---|
| 纸面 | `--paper` | `#f7f5f1` | 页面底色（暖白，不是纯白，降低长时间阅读的刺眼感） |
| 卡片面 | `--paper-raised` | `#ffffff` | 表单与卡片 |
| 凹陷面 | `--paper-sunken` | `#efebe4` | 表头、只读区、被停用行的整行灰化 |
| 主文字 | `--ink` | `#16181d` | 深墨，不纯黑 |
| 主色 | `--indigo` | `#2f5d62` | 靛青：主按钮、分类签、当前导航 |
| 主色派生 | `--indigo-hover` / `--indigo-active` / `--indigo-tint` | `#274e52` / `#1e3f43` / `#e8efef` | 明度阶梯 + 纸面混色，保证悬停/激活有层次而不换色相 |
| 点缀 | `--amber` | `#e8a33d` | 琥珀：只用于"需要注意"（未读红点、统计牌顶条、头像贴片顶条），**不作正文色** |
| 语义 | `--danger` / `--success` | `#c0453b` / `#3f7a55` | 危险与成功 |
| 细边 | `--rule` | `#e2ddd4` | 1px 分隔线（全站主要的分隔手段） |

### 形状：1px 细边 + 2–4px 小圆角 + 3px accent 条

卡片不用阴影堆叠，用 `--border-hair` 细边加顶部 3px `--border-accent` 条表达层级；
阴影只留给浮层（模态、菜单），见 `--shadow-overlay`。默认控件高度 34px、大号 40px。

### 字体：衬线标题 + 无衬线正文 + 等宽数据

```css
--font-display: 'Fraunces', 'Noto Serif SC', Georgia, serif;
--font-body:    'Inter', system-ui, 'Microsoft YaHei', sans-serif;
--font-mono:    'JetBrains Mono', Consolas, monospace;
```

- 标题与刊头走衬线，给"册子"的质感；
- 正文走无衬线，保证小字号可读；
- **所有 ID、时间、状态、统计数字走等宽**——它们是需要逐位核对的数据；
- 只用 CSS 字体栈，**不联网加载 webfont**，离线构建与专网部署都能跑。
- 字号阶梯按 1.2 比例（10.5 → 40px），标签用小写字距 `--tracking-label: 0.16em`。

### 间距与布局

4 的倍数间距阶梯（`--sp-1` … `--sp-10`）；内容区最大宽 `1120px`、12 栅格、间距 20px；
左侧导航深墨底宽 `220px`，`≤768px` 折叠成 52px 顶部图标条。

### 动效：只留两处

全站只有两条 `animation`（头像裁剪面板展开、通知红点脉冲），时长 `200ms`、
缓动 `cubic-bezier(.2,0,0,1)`，并且 `prefers-reduced-motion: reduce` 会同时关掉它们。
其余交互不加入场动画、不做悬浮位移。加载态刻意用等宽文字
（`正在载入···`，`role="status"`）而不是转圈。

## 3. 三个页面的具体决策

### 登录页（`LoginView.vue`）— 封面 + 表单，不是居中卡片

左半幅深墨封面 + 30px 横格纸线，衬线刊头「个人档案」，等宽卷号
`UC-000001 / 第 1 册`，下面是 `01/02/03` 的「本册内容」目录——这组编号对应真实的三册
（资料 / 登录与安全 / 通知），不是装饰性序号。右半幅是纸面表单，标题带 3px 靛青分类签。
没有渐变球、没有玻璃拟态、没有插画。

### 资料页（`ProfileView.vue`）— 底册式 ledger

身份区是 `.ledger`：label/value 行用 1px 细线分隔，值为等宽字体，最近登录写「相对 + 绝对」两遍。
头像是 112px **方块贴片**（1px 边框 + 3px 琥珀顶条），不是圆形 + 渐变环。
有未保存改动时只出现一行等宽小字，不做吸底保存条。

### 用户管理台（`AdminUsersView.vue`）— 计数牌 + 印章

6 项统计是 `.docket` 横带：一条 1px 边框、6 格、琥珀顶条、数字等宽，替代"4 张圆角统计卡 + 图标"。
状态一律用**印章**（左侧 3px accent + 字距 0.16em 的小写标签）；`DISABLED` 额外整行灰化 +
右上角**斜纹角标**（`--hatch-size` 缩到单元格尺度的 14px），不用彩色胶囊。

## 4. 可访问性

- 正文对比：纸面上 `--ink` ≈ 16:1、`--ink-muted` ≈ 7:1；`--ink-faint`（≈4.6:1）只用于大字号或非关键文字。
- 深墨底上的靛青统一用 `--indigo-on-dark`（≥4.5:1），不在深底上直接用 `--indigo`。
- 琥珀底上的文字用 `--amber-ink`，不用纯黑或纯白。
- 焦点可见、表单控件都有 label、状态不只靠颜色区分（印章 + 文字 + 斜纹）。
- 375px 宽度下：侧栏折叠为顶部图标条、表格横向滚动、统计牌换成 2 列。

## 5. 代码级自检（可复现）

```powershell
cd frontend
# 组件/视图里不应有色值字面量
Select-String -Path src\**\*.vue -Pattern '#[0-9a-fA-F]{3,6}' | Where-Object { $_.Line -notmatch 'var\(--' }
# 动效数量
Select-String -Path src\**\*.vue,src\**\*.css -Pattern 'animation:' 
# 不允许 v-html
Select-String -Path src -Pattern 'v-html' -Recurse
```

当前结果：颜色字面量为 0（唯一 `#ffffff` 是头像 canvas 导出兜底色，也从 `--paper-raised` 读取，
读不到才回退）；`animation` 恰好 2 条；`v-html` 0 处。

## 6. 明确不做

- **不做深色模式/主题切换**（需求里未勾选，因此不引入第二套色板，避免"半套主题"）。
- 不引入 Element Plus / Ant Design 等 UI 框架：它们会立刻把界面拉回模板脸。
- 不做插画、渐变球、玻璃拟态、大圆角阴影卡片。
- 不用 webfont 联网加载。
